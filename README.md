https://cravedl.github.io

## Write a New Post

Create a new Markdown file under `_posts` using this filename format:

```text
YYYY-MM-DD-post-title.md
```

Each post should start with front matter:

```markdown
---
layout: post
title: "Post Title"
date: 2026-05-25
categories: [RAG, NLP]
---
```

Then write the article in Markdown.

## Local Preview

GitHub Pages will build this automatically after pushing to the `main` branch. Local preview is optional.
